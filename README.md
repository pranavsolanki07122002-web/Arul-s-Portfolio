# Arul Raghuwanshi — Portfolio

Static site. No build step.

- **GitHub:** upload this whole folder (keep `index.html` and the `media/` folder side by side).
- **Vercel:** New Project → import the GitHub repo → Framework preset: **Other** → Deploy. No build command, no output directory.
- **Local preview:** open `index.html` in a browser, or run `npx serve .` in this folder.
